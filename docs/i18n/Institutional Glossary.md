# Nexus — Institutional Glossary (F-181)

**Consistent translations for school terminology**

---

## Purpose

This glossary defines how institutional terms are translated across all three languages, so every translator and content editor uses the same wording rather than each producing their own. This is what keeps a phrase like "Principal" or the school motto consistent across every page, form, and PDF the platform generates.

**Status: substantially real for Sinhala, mostly outstanding for Tamil.** This document previously existed only as an empty placeholder, while its actual content — everything below — had been misplaced inside `Translation Workflow.md`. It's been moved to its proper home. I haven't verified the accuracy of the Sinhala text myself; it's carried over as-is from where it was already recorded in the repo, not something to take on faith without a fluent reviewer checking it.

## Using the Glossary

### For Translators

1. Check the glossary first when translating a term.
2. Use the exact translation from the glossary.
3. If a term is not in the glossary, add it here.
4. Maintain consistency across all files.

### For Developers

1. Use the English term consistently in code.
2. Do not change the English source text without updating translations.
3. When adding a new feature, update the glossary.

## Important

**Do not fill the "_needs translation_" gaps with machine-translated or AI-generated text.** These are official institutional terms that will appear publicly, in some cases effectively in the Principal's own name — they need sign-off from someone with real fluency and institutional authority (a Sinhala/Tamil-medium teacher, ideally with the Principal's review), the same way the existing Sinhala entries above were presumably sourced.
