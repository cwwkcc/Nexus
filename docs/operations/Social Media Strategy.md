# Nexus — Social Media Strategy

**Managing the school's official social media presence**

---

## Overview

Social media is a core component of Nexus — it is the school's digital face alongside the website. This document defines the strategy, content guidelines, and management workflow for the school's official social media accounts.

### Account Ownership

All accounts must be owned by the school:

- Use `contact@cwwkcc.lk` email address for all accounts
- Passwords stored in a password manager accessible to the school administration
- At least two people have access to each account
- Student accounts should not be the primary owners

### Transferring Existing Accounts

If unofficial accounts already exist:

1. Identify all existing accounts (Facebook pages, Instagram accounts, etc.)
2. Coordinate with the current administrators to request transfer
3. Document the transfer with the school administration's approval
4. Bring accounts up to the official visual identity and content standards

## Content Creation

### Post Structure

**Facebook/Instagram:**

- 1-2 sentence introduction
- 2-3 paragraphs of content (or bullet points)
- 1-3 high-quality images
- Relevant hashtags (#KCC #Kannangarians #WisdomIsAllWealth)
- Call to action (Learn more, Comment, Share)

**YouTube:**

- Title: Event name + description
- 1-2 paragraph description
- Relevant tags
- End screen with school logo and website link

**WhatsApp Channel:**

- Short, direct message
- Clear call to action
- Link to the website for more details

### Brand Guidelines

**Visual Identity:**

- Use school crest and colours consistently
- Cover photos should include the school name and crest
- Profile photos should be the school crest or logo

**Tone:**

- Formal but welcoming
- Educational and informative
- Proud of heritage but not arrogant

**Language:**

- Sinhala for community posts
- English for official announcements
- Tamil for regional engagement

## Management Workflow

### Post Creation Workflow

1. **Draft** — Editor creates a draft post in the Social Media Management Module
2. **Review** — Staff Advisor reviews for accuracy and appropriateness
3. **Approve** — Staff Advisor approves the post
4. **Schedule** — Editor schedules the post for the appropriate time
5. **Publish** — Editor publishes to all platforms (manually or via API)
6. **Engage** — Editor responds to comments and messages

### Post Approval Process

| Post Type               | Who Creates         | Who Approves              |
| ----------------------- | ------------------- | ------------------------- |
| Regular news            | KITS Editor         | Staff Advisor             |
| Important announcements | KITS Editor         | Staff Advisor + Principal |
| Exam results            | Examinations Office | Principal                 |
| Historical content      | KITS Editor         | Staff Advisor             |
| Urgent updates          | KITS Editor         | Staff Advisor             |

### Content Calendar

Use the Social Media Management Module's calendar view:

- Plan posts 2 weeks in advance
- Align with school events and announcements
- Balance content pillars
- Review and adjust weekly

## Engagement Guidelines

### Responding to Comments

| Response Type     | Action                                         |
| ----------------- | ---------------------------------------------- |
| Positive comments | Like and respond with gratitude                |
| Negative comments | Respond professionally, take offline if needed |
| Questions         | Answer promptly and accurately                 |
| Spam              | Delete and block                               |

### Response Times

| Platform         | Response Time              |
| ---------------- | -------------------------- |
| Facebook         | Within 24 hours            |
| Instagram        | Within 24 hours            |
| WhatsApp Channel | As needed (broadcast only) |
| YouTube          | Within 48 hours            |

### Crisis Communication

If a negative incident occurs:

1. **Pause** all scheduled posts
2. **Coordinate** with the school administration
3. **Draft** a response with the principal's approval
4. **Publish** a single, unified response
5. **Monitor** all platforms for follow-up questions
