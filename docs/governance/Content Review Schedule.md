# Nexus — Content Review Schedule

**Regular review cycles for all content**

---

## Purpose

This document defines the review schedule for all content on the Nexus platform. Regular reviews ensure content remains accurate, current, and high-quality.

---

## Review Cycles

| Cycle         | Frequency      | Purpose                 |
| ------------- | -------------- | ----------------------- |
| **Daily**     | Every day      | Check for urgent issues |
| **Weekly**    | Every week     | Review recent changes   |
| **Monthly**   | Every month    | Review content quality  |
| **Quarterly** | Every 3 months | Review content accuracy |
| **Annually**  | Every year     | Full content audit      |

---

## Daily Review

**Owner:** KITS Lead

**Tasks:**

- [ ] Check UptimeRobot alerts
- [ ] Review server logs
- [ ] Check database backups completed
- [ ] Verify site is accessible

---

## Weekly Review

**Owner:** Staff Advisor

**Tasks:**

- [ ] Review analytics (traffic trends)
- [ ] Review pending content (drafts, approvals)
- [ ] Check social media engagement
- [ ] Review audit log for unusual activity
- [ ] Check security updates

---

## Monthly Review

**Owner:** Staff Advisor + Section Owners

**Tasks:**

### Content Review

- [ ] Review news articles (archived/outdated)
- [ ] Review events (upcoming/past)
- [ ] Review gallery albums (quality)
- [ ] Review staff profiles (updates)

### Quality Review

- [ ] Check image alt text
- [ ] Check link health
- [ ] Check accessibility (Lighthouse)
- [ ] Check SEO metadata

### Social Media Review

- [ ] Review social media engagement
- [ ] Update content calendar
- [ ] Review followers and reach

---

## Quarterly Review

**Owner:** Staff Advisor + Editorial Team

**Tasks:**

### Content Accuracy

- [ ] Review all page content
- [ ] Update outdated information
- [ ] Remove obsolete content

### Accessibility

- [ ] Run accessibility audit
- [ ] Fix any violations

### Performance

- [ ] Run Lighthouse audit
- [ ] Fix any performance issues

### Governance

- [ ] Review content governance document
- [ ] Update policies if needed

---

## Annual Review

**Owner:** Principal + Staff Advisor

**Tasks:**

### Full Content Audit

- [ ] Audit all page content
- [ ] Audit all staff profiles
- [ ] Audit all society information
- [ ] Audit all facility information
- [ ] Audit all academic program information

### Governance Review

- [ ] Review content governance policy
- [ ] Review roles and responsibilities
- [ ] Review approval workflow
- [ ] Update all governance documents

### Strategic Review

- [ ] Review platform usage
- [ ] Review content strategy
- [ ] Plan for next year
