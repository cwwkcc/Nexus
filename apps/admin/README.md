# Nexus Admin CMS

The administrative content management system for Nexus.

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Run production build
pnpm start
```

## Features

- Content management (news, events, pages, etc.)
- Media library
- User management
- Analytics dashboard
- Design system showcase

## Tech Stack

- Next.js 15
- React 19
- Tailwind CSS
- TypeScript

## Authentication

Authentication is currently in development (F-062/F-063). The middleware passes all requests through until Google Workspace OAuth is implemented.
